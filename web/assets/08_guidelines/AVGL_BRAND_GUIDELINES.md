# AVGL Layered Projection Brand System v1.0

## Brand idea
**One model. Many lenses.**

The mark expresses one underlying system viewed through multiple semantic projections. The central object is stable; layered planes represent lenses; the blue ray represents selected effect/projection.

## Core principles
1. **STRUCTURE = EFFECT** - structure includes what it governs and affects.
2. **ONE MODEL -> MANY LENSES** - every view derives from the same system model.
3. **UNKNOWN STAYS UNKNOWN** - visual confidence must never exceed evidence.

## Logo usage
- Prefer the primary horizontal lockup in documentation and marketing.
- Use the symbol alone for app icons, favicons, avatars and dense UI.
- Keep at least one central-cube width of clear space around the mark.
- Do not distort, rotate, add gradients, or recolor individual projection planes.
- AVGL Blue (#0066FF) is the active/projection accent, not a decorative fill.

## Typography
- Sans: Inter / Helvetica Neue / Arial / system sans
- Editorial: Georgia or equivalent restrained editorial serif
- Technical: IBM Plex Mono or system monospace
- Font files are intentionally not bundled.

## Iconography
24x24 canonical grid, 1.75px stroke, square-to-subtle-rounded terminals. Geometry communicates semantics; color only reinforces it.

Core: Object, Space, Boundary, Relation, Flow, State, Transformation, Identity.

Lenses: Structure, Agentic, Context, Inheritance, Propagation, Effective, Evidence.

## States
Use modifiers rather than changing the base object identity. Blue = selected/active, green = verified/success, amber = attention, red = error/blocked, gray = unknown/inactive.

## Motion
Lens switching should preserve object position where practical and change emphasis rather than replacing the system. Propagation may animate as a one-shot pulse along a path.
