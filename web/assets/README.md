# AVGL Full Asset Package

Concept: **Layered Projection / One model. Many lenses.**

This bundle contains production-ready vector/raster brand assets, favicons/app icons, design tokens, iconography, UI illustrations, marketing assets, the original concept reference, source sprites, and brand guidelines.

## Folders
- `01_logos` - symbol, wordmark, horizontal/stacked/technical lockups
- `02_favicon_appicons` - favicon, ICO, app icons, webmanifest
- `03_foundations` - palette, tokens, typography guidance
- `04_iconography` - core primitives, lenses, UI and state icons
- `05_ui_assets` - empty states and patterns
- `06_marketing` - OG, social, poster
- `07_mockups_reference` - selected concept reference
- `08_guidelines` - Markdown + PDF brand guide
- `09_source_files` - SVG symbol sprite

## Font note
No font files are bundled. Use the documented font stacks or properly licensed fonts in production.
